is listed here. In-game credits must render this file (or an equivalent
summary) verbatim.

## Format
```
### <asset / dataset name>
- Source: <URL>
- License: <SPDX id or free text>
- Used for: <what it drives in the game>
- Credit line: "<how it must appear in-game>"
```
